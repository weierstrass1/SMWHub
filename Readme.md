# SMWHub

SMWHub is a content management system for Super Mario World ROM hacking. It is responsible for reading, processing, and installing resource packages into a ROM.

Rather than hardcoding support for specific resource types, SMWHub uses an extensible plugin system. External plugins define how different kinds of packages are read, processed, and installed, allowing the tool to support new resource types without modifying its core.

The goal of SMWHub is to provide a modern, extensible, and maintainable resource management ecosystem for Super Mario World, making the installation and organization of resources significantly easier than traditional workflows.
